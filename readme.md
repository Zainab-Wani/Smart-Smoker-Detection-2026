# Smart Vision-Based Smoking Detection for Restricted Areas

## Overview
This project uses Computer Vision and Deep Learning to detect smoking activity in restricted areas using YOLO, MediaPipe, and OpenCV.

## Features
- Real-time smoking detection
- YOLO object detection
- MediaPipe landmark detection
- Alert generation
- Dataset preprocessing and auto-labeling

## Technologies Used
- Python
- OpenCV
- YOLO (Ultralytics)
- MediaPipe
- TensorFlow
- NumPy
- Tkinter

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python model1.py
```
